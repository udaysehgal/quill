quill

A Scheme compiler that emits ARM64 machine code, running in your browser as WebAssembly. Edit the program and the listing updates as you type.

The browser can't run the output, because quill writes native code for Apple Silicon. Building it on a Mac takes three commands, and needs Rust and the Xcode command line tools.

git clone https://github.com/udaysehgal/quill && cd quill
cargo build --release
./target/release/quill examples/queens.scm -o queens && ./queens
